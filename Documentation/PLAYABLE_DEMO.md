# Playable Demo Setup

The repository includes a Unity Editor command that creates a generated 2D battle test scene. Runtime placeholder shapes are intentional for this first playtest.

1. Open the project in Unity 6000.0.60f1 and wait for package import and script compilation.
2. Choose **Kingdom Last Stand → Create Demo Battle Scene** from the editor menu.
3. Press **Play**.
4. Recruit at least two Archers, drag one onto the other to merge, recruit defenders, then start the wave.
5. Watch the castle health and gold. After the battle, use **Restart** to replay.

The scene builder adds its scene to Build Settings. Generated models, colors, wave data, and the basic HUD are runtime placeholders. This is a combat-loop preview, not the finished art or full campaign.
